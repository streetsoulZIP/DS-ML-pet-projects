# Underwater semantic segmentation (SUIM)

## Задача

Сегментация подводных изображений SUIM на 8 классов: фон/вода, растения, дно, водолазы, роботы, рифы и другие объекты. Основная сложность — сильный дисбаланс пиксельных классов и неконсистентные размеры изображения и маски.

## Реализация

- сопоставление RGB-изображений и цветных масок; в исходном коде обработаны 37 случаев неконсистентного размера;
- resize по короткой стороне, class-aware crops 512×512, ограничение перекрытия и sampling с учётом редких классов;
- синхронные геометрические аугментации `Albumentations` и отдельные цветовые преобразования для изображения;
- `FocalLoss + DiceLoss + IoULoss`, class weights, DeepLabV3+ и U-Net с EfficientNet-B3/B6;
- анализ mIoU, Dice, PA, mPA, confusion matrix и показателей по классам.

Код эксперимента: [underwater-semantic-segmentation.ipynb](underwater-semantic-segmentation.ipynb).

## Результаты

Лучший зафиксированный вариант — **DeepLabV3+ + EfficientNet-B6 (fine-tune)**: локальная валидация **mIoU 0.833**, Dice 0.8702, PA 0.8663, mPA 0.8401. Для сравнения, U-Net + EfficientNet-B6 достиг mIoU 0.792. Эти показатели не являются leaderboard-результатами.

Сохранённые outputs удалены намеренно; метрики перенесены из подтверждённого описания проекта, а не извлечены из старых outputs.
