# Обзор портфолио

## Профиль

Прикладной ML: табличные данные, NLP, Computer Vision, временные ряды, генерация данных и retrieval. Полные структурированные записи находятся в [`portfolio/catalog.json`](portfolio/catalog.json).

## Проекты

Исходные проекты: `semantic-retrieval-films`, `llm-film-data-generation`, `student-employment-tabular`, `russian-news-classification`, `demand-forecasting`, `sports-image-classification`, `underwater-semantic-segmentation`, `building-energy-regression`. Их показатели перенесены без изменения смысла из ранее подтверждённого README и имеют статус `user_confirmed_readme`.

Импортированы без заявленных метрик: `dns-review-sentiment`, `fake-news-detection`, `roberta-ner`, `speech-sentiment`, `spotify-topic-recommender`, `chess-move-probabilities`. Последний включает сохранённый файл весов `Hybrid.pt`, необходимый для использования решения.

## Соревнования

`data-fest-2026-track-2` — участие в Data Fest 2026 (multitarget binary classification, 41 таргет). Опубликованное решение находится в [отдельном репозитории](https://github.com/streetsoulZIP/Hackatons-and-ML-competions). Официальный итог и личный вклад сверх доступного решения не установлены; призовое место не заявляется.

## Статусы результатов

`user_confirmed_readme` означает метрику, перенесённую из подтверждённого пользователем основного README. `unknown` означает, что надёжный результат в доступных материалах не установлен. Старые notebook outputs не являются подтверждением.
